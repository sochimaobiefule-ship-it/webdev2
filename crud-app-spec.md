# Product Inventory Management System — Specification

## Overview
A lightweight Spring Boot web application designed for managing product inventory in a retail context. The application allows store administrators to track product details, update stock levels, and remove discontinued items.

## Functional Requirements
* **REQ-1 (Create):** The system shall allow users to add a new product to the inventory by providing a name, category, price, and stock quantity through a web form.
* **REQ-2 (Read):** The system shall display a list of all current products in an HTML table, along with detailed views for individual products by ID.
* **REQ-3 (Update):** The system shall allow users to edit existing product details via a pre-populated form and persist the modified data.
* **REQ-4 (Delete):** The system shall allow users to permanently delete a product from the inventory via a dedicated action link or button.
